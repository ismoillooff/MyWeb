# Contributing

Thanks for your interest in improving this project!

## How to contribute

1. **Open an issue first** for bugs or feature ideas, so the change can be discussed.
2. **Fork** the repository and create a branch from the default branch:
   `git checkout -b feature/short-description`
3. Make your changes. Keep them focused — one topic per pull request.
4. Follow the existing code style, and run the project's linters and tests before pushing.
5. Write clear commit messages (e.g. `fix: handle empty phone number`).
6. Open a **pull request** describing what changed and why. Link the related issue.

## Reporting bugs

Please include steps to reproduce, the expected and actual behaviour, and your
environment (OS, runtime versions, browser if relevant).

## Security issues

Do not report security vulnerabilities in public issues — see [SECURITY.md](SECURITY.md).
