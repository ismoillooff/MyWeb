# Security Policy

## Reporting a vulnerability

If you find a security vulnerability in this project, please **do not open a public issue**.
Report it privately instead:

- Email: ismoillooff@gmail.com
- Telegram: https://t.me/ismoillooff

Please include:

- a description of the issue and its possible impact;
- steps to reproduce (or a proof of concept);
- the affected version, commit or URL, if known.

You will get an acknowledgement within 72 hours. Once the issue is confirmed, a fix
will be prepared and released as soon as possible, and you will be credited if you wish.

## Supported versions

Only the latest version on the default branch receives security fixes.
